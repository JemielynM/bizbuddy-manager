# BizBuddy Inventory Management System

## Overview
BizBuddy is a business inventory and order management web application built using Angular, PHP, and MySQL.

## Features
- User Login & Registration
- Product Management
- Customer Management
- Orders Module
- Dashboard Statistics
- Search & Sorting

## Technologies Used
- Angular
- TypeScript
- PHP
- MySQL
- HTML/CSS

## Installation
1. Run XAMPP
2. Import database into phpMyAdmin
3. Run Angular frontend:

```bash
ng serve
```

4. Open:
http://localhost:4200

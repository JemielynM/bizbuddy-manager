
# BizBuddy Manager

## Project Overview
BizBuddy Manager is a web application prototype designed to help small business owners manage customers, products, inventory, and orders in one centralized system.

## Problem Statement
Many small businesses rely on spreadsheets or manual tracking, which can lead to errors, inefficiencies, and lost information. This application aims to simplify business operations through an easy-to-use web interface.

## Features
- User registration and login
- Customer management (CRUD)
- Product and inventory management (CRUD)
- Order creation with multiple items
- Automatic order total calculations
- Order status tracking (Draft, Paid, Shipped)
- Basic dashboard overview (optional)

## Tech Stack
- Backend: PHP, MySQL
- Frontend: Angular
- Version Control: GitHub
- Project Management: GitHub Projects
